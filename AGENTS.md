# AGENTS.md

## Project Context
OregonVR is a team capstone project in its initial development stage.

- **Repository:** https://github.com/swath1p/OregonVR

## Coding Rules
- Write clear, maintainable code.
- Follow existing project conventions.
- Keep changes focused and document important updates.
- Do not assume tools or features exist before they are implemented.

## Testing
- Add or update tests when appropriate.
- Run available tests and quality checks.
- Report results honestly.
- Follow the Definition of Done in `CONTRIBUTING.md`.

## AI and Confidentiality
- Never share passwords, API keys, or secrets with AI tools.
- Do not share partner-confidential information unless explicitly authorized.
- Ask the AI Coordinator if unsure what can be shared.
- Review AI-generated code before accepting it.

Owners will update this file as the project develops. These items are planned and are not yet confirmed as implemented.
